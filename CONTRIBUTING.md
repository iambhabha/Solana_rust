# Contributing to Solana Token Backend

Thank you for your interest in contributing to the Solana Token Backend project! We welcome contributions from the community to help make this project better.

## How to Contribute

1.  **Fork the Repository**: Click the "Fork" button on the top right of the repository page.
2.  **Clone your Fork**: `git clone https://github.com/YOUR_USERNAME/Solana_rust.git`
3.  **Create a Branch**: `git checkout -b feature/amazing-feature`
4.  **Make Changes**: Write your code and tests.
5.  **Commit Changes**: `git commit -m "Add amazing feature"`
6.  **Push to Branch**: `git push origin feature/amazing-feature`
7.  **Open a Pull Request**: Submit your PR on the original repository.

## Coding Standards

*   **Rust**: We follow standard Rust formatting. Please run `cargo fmt` before submitting.
*   **Testing**: Ensure all tests pass by running `cargo test`.
*   **Documentation**: unexpected behavior should be documented.

## Reporting Issues

If you find a bug or have a feature request, please open an issue using the provided templates.

## Code of Conduct

Please be respectful and professional in all interactions. We want to create a welcoming environment for everyone.
